# 转正答辩

答辩委员会不在评估你"忙不忙"，在评估三件事：**你能不能独立负责一件事、你适不适合这个团队、留下你值不值**。

## 工作流程

1. **先立主线**：几个月的工作必须能被一句话概括。想不出这句话，就说明你自己也没想清楚价值在哪。
   - 差：`参与了订单系统的开发`
   - 好：`把订单导出从人工跑脚本变成自助页面，运营每月省 20 人时`
2. **选 2-3 件事展开**，每件事按：背景 → 你做了什么 → 结果 → 从中得到什么。
3. **处理"杂活"**：写文档、修数据、配合排查——这些不是没价值，是要讲成"我补上了团队的某个缺口"。
4. **准备被质疑的三个点**：为什么这么做、有什么没做好、如果继续你会做什么。
5. **给"留下后的计划"**：这是评委最想听的，也是多数人漏掉的。

## 输出格式

```markdown
## 🎯 一句话主线

> ...

## 📖 主体（2-3 件事）

### 1. <标题，动词开头>

- **背景**：...
- **我做的**：...（说清哪些是你独立完成的）
- **结果**：...（数字 / 影响范围 / 谁在用）
- **收获**：...

### 2. ...

## 🔧 那些看起来零碎的工作

| 做的事 | 实际价值 |
|---|---|
| ... | ... |

## ⚠️ 预判质疑

| 评委会问 | 你的答案要点 |
|---|---|
| 这件事为什么是你做，不是别人？ | |
| 有什么没做好的？ | |
| 如果给你更多时间，你会怎么改进？ | |
| 你觉得这个方案有什么问题？ | |

## 🚀 留下之后的计划（30/60/90 天）

- **第一个月**：...
- **第二个月**：...
- **第三个月**：...

## 🙋 我有什么问题想问（反问环节）

1. ...
2. ...

## 📋 时间分配建议

- 开场主线：30 秒
- 主体：3-4 分钟
- 反思与计划：1 分钟
- 留 1-2 分钟给提问（**不要讲满**）
```

## 判断原则

- **不要按时间顺序讲**：按"价值"讲。三个月做的事，重要的一件讲 2 分钟，其余打包 30 秒。
- **"没做好"必须真的说一个**：说"没有不足"会被认为缺乏自省。选一个真实的、且你已有改进思路的。
- **数据要能对上**：说"提升 30%"，评委可能问"怎么测的"。准备好口径。
- **别抢团队的功，也别埋自己的功**：用"我负责 X，和 Y 同学配合完成 Z"这种句式，界限清楚。
- **反问环节不要说"没有问题"**：准备两个真问题（比如团队接下来三个月最想解决的技术问题是什么），这会显得你真的在考虑留下。
- **中文语境**：国内实习转正通常有"述职 PPT + 评委提问"，时间 10-15 分钟，评委常是直属 leader + 跨组 leader + HR。
