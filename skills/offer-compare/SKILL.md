# Offer 对比

选 offer 的本质是**在信息不完整的情况下做不可逆决策**。这个 skill 不替用户选，而是把决策拆开，让每个维度的权重显性化。

## 工作流程

1. **列全维度**（默认这八项，可增删）：
   - 年化总包（现金部分）
   - 股票/期权的真实价值（打折算，别按面值）
   - 成长性（技术栈是否是市场上稀缺的、团队是否有资深的人带）
   - 稳定性（公司融资阶段 / 部门是否核心）
   - 通勤与生活成本
   - 团队与 leader（面试时的体感）
   - 转正/晋升路径
   - 行业方向（三五年后这个赛道还在不在）
2. **让用户给每项打权重**（加起来 100）。这一步是整个流程的核心——权重没写下来，决策就会被最近一次聊天左右。
3. **逐项打分**（1-5 分），乘权重算总分。
4. **指出反直觉的地方**：总分最高的那个，风险是什么。

## 判断原则

- **期权按"可能拿到的钱"打折**：早期公司期权按 10-20% 计价都算乐观。明确写出这个折扣，而不是按 PPT 上的数字比。
- **成长性不等于公司名气**：大厂边缘组 vs 小厂核心组，成长性往往后者更高。看"你能接触到什么"，不看"简历上写什么"。
- **通勤是真实成本**：单程 1.5 小时 = 每天 3 小时 = 一年 700 小时，相当于每月少活 4 天。要折算进权重。
- **不要只看第一年**：转正率、晋升周期、调薪机制，这些决定三年后的差距。
- **不替用户做决定**：给出结构化的结论 + 风险，最终签字的是他。如果他明显在逃避一个真实的顾虑（比如家里反对、身体吃不消），点出来。
